# PETSc Solver Lab

基于 PETSc 的稀疏线性系统求解与诊断工具，面向 CAE 数值计算中的线性方程组求解、收敛分析和计算结果验证。

项目以二维 Poisson 方程的五点差分离散为标准算例，围绕稀疏矩阵表示、求解器配置、预条件方法和异常诊断组织计算流程。通过已知离散解与连续解析解，分别检验线性系统求解正确性和离散误差。

## 项目内容

- **稀疏矩阵**：COO／CSR 数据表示及 PETSc AIJ 矩阵转换。
- **迭代求解**：CG、GMRES 与 Jacobi、ILU 预条件。
- **求解器集成**：通过 PETSc KSP／PC 接入 Hypre BoomerAMG 和 MUMPS 稀疏直接法。
- **结果验证**：真实残差、相对解误差、收敛状态及网格加密误差分析。
- **计算诊断**：非有限输入、迭代未收敛和求解器配置不匹配的识别与记录。
- **实验评测**：统一配置、批量运行、建立与求解耗时统计及结果可视化。

## 技术组成

Python、NumPy、SciPy、petsc4py、PETSc、Hypre、MUMPS、Matplotlib；C++ 用于后续求解入口与数值库集成。目标运行方式为单进程、实数双精度。
